# Hawaii Itinerary

A responsive Hawaii itinerary website connected live to the trip's Google Sheet. The public site reads normalized events from `Timeline!A1:J200` and food ideas from the `Food` tab. Optional `Description` and public HTTPS `Image` values create expandable event cards.

To publish, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
